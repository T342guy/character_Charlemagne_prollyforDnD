# **<ins>Abilities:</ins>**
## **The "collar"**
The collar can induce pain of any severity to the host at will of the entity. _<ins>This pain is theoretical and not physical.</ins>_ **The host takes <ins>no damage</ins>**, they experience all of it from the collar. The entity can induce pain at any time _for any duration no longer than 45 seconds_. The entity is a logical, good entity. **SHOCKING MUST HAPPEN WITH REASON! NO REASON SUPPLIED IS INVALID! It must be supplied with reason. Example: anger, offense, displeasure.**
## **Influence**
The entity can change your views unknowingly! You may seem to like more things then others or have other mixed feelings of events! For example: if someone were to say something bad about entities in general, you, the host, would probably feel extremely offended!
## **(you are being) Kontroled**
It fights you! The entity will fight for control of the host's body at times. 
### **ASSERT!**
The entity can sometimes take control of the host! If the entity wanted to ASSERT! control, it would say what it wanted to ASSERT!. The Things you can ASSERT! Are the limbs and body.
How to roll for ASSERT! When you roll for ASSERT!, roll for the main “Kontrol!”. Then roll again for “NIEN!”. If the “Kontrol!” roll is the highest number, Roll for “NIEN!” anyways. If both end up being the highest number, re-roll the entire set of “Kontrol!” and “NIEN!” again. Don't do this if the roll is normal. Normally, roll for “Kontrol!”.\
If the “Kontrol!” roll number is higher then the “NIEN!” number, the ASSERT! was successful. Then the limb or body can be taken control of.\
MAKE SURE TO USE THE DICE LISTED!
> [!TIP]
> Takeover via entity is called “Kontrol!”. Resistance via the host is called “NIEN!”.
    - limbs – **(USE 1d6, no more then one limb at a time)** The entity may attempt to take over a limb. That limb may be put into a static or dynamic position. THIS CANNOT LAST FOR LONGER THEN 1 MIN!
